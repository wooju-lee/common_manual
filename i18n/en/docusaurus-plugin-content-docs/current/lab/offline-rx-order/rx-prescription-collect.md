# 📍 RX Prescription 수집

> RX 주문에 필요한 필수 정보를 수집 · 저장하고, 스토어에서 Lab으로 출고를 등록하는 과정을 안내합니다.
>
> 경로 : <span className="path-badge">POS > RX Operation</span>

---

## 1. 필수 정보 저장

RX 주문을 진행하려면 아래 4가지 필수 정보를 수집 · 저장해야 합니다.

### 1-1. 멤버십 정보

고객 멤버십을 주문에 매핑하고, .com 마이페이지에 등록된 처방 정보를 불러오기 위해 필요합니다.

**조회 방법**

| 조건 | 설명 |
|---|---|
| **국가** (필수) | 고객이 속한 국가를 선택합니다 |
| **이메일 또는 전화번호** | 이메일(ID@) 또는 핸드폰 번호(8자리 이상)로 조회합니다 |
| **멤버십 QR 스캔** | .com 마이페이지의 멤버십 QR을 스캔하여 정확하게 조회합니다 |

:::info 개인정보 마스킹 안내
- **이메일 / 전화번호 조회** 시 : 조회 조건이 아닌 항목은 마스킹 처리됩니다. (예: 이메일로 조회 → 전화번호 마스킹)
- **멤버십 QR 스캔** 시 : 모든 정보가 마스킹 없이 조회됩니다. **운영에서 최대한 활용을 권장합니다.**
- 비회원의 경우 **Non-Member**로 설정하면 비회원 주문 정보로 관리됩니다.
:::

**처방정보 불러오기**

멤버십 설정이 완료되면, .com 마이페이지에 사전 등록된 처방정보 목록이 자동으로 조회됩니다.

| 항목 | 설명 |
|---|---|
| 처방전 선택 | 목록 중 **1개를 선택**합니다 (처방전당 이미지 최대 3개) |
| 만료일 체크 | 만료일(EXP Date)이 오늘이거나 과거인 처방 정보는 조회되지 않습니다 |
| 자동 반영 | 선택된 처방정보는 Prescription Information에 자동 입력되며, **수정할 수 없습니다** |

> 2026.05 오픈 전에 등록된 처방정보는 만료일자 정보가 없을 수 있습니다.

---

### 1-2. 처방 정보 (Prescription)

멤버십을 통하지 않고 직접 수집하는 경우, 아래 항목을 입력합니다.

| 항목 | 설명 | 입력 범위 | 비고 |
|---|---|---|---|
| **Sphere (SPH)** * | 근 / 원시 교정 기본 도수 | -10.00 ~ +5.00 | |
| **Cylinder (CYL)** * | 난시 도수 | -6.00 ~ +3.00 | 0.25 단위, 소수점 2자리 |
| **Axis** * | 난시 교정 각도 | 0 ~ 180 | 정수만 입력 |
| **PD** * | 양쪽 눈동자 중심 거리 | 1 ~ 100 | 소수점 2자리 허용 |
| **OC** | 동공 중심 위치 | 0 ~ 40 | 정수만 입력 |

> `*` 표시 항목은 필수 입력입니다.

---

### 1-3. 기본 고객 정보

이름, 이메일, 전화번호, 배송 타입, 주소를 입력합니다.

- 멤버십 처방전 정보로 처리한 경우, 고객 정보가 함께 반영되며 **수정이 가능**합니다.

:::caution 주의
멤버십 조회 방식에 따라 마스킹된 정보가 반영될 수 있으며, 이 경우 **저장이 실패할 수 있습니다.** 마스킹된 항목은 직접 수정 후 저장해 주세요.
:::

---

### 1-4. 개인정보 활용 및 의료 정보 수집 동의

고객에게 처방정보 및 개인정보 활용에 대한 동의를 받아야 합니다.

| Step | 내용 |
|:---:|---|
| **a** | HIPAA, RX 주문 활용 동의 등 정책 내용을 고객에게 안내합니다 |
| **b** | 고객의 **시그니처(서명)**를 수집합니다 |

---

## 2. 저장 완료 후 상태 변경

필수 정보를 모두 저장하면, 주문 상태가 `Unready` → `Request`로 업데이트됩니다.

- `Request` 상태가 되면 <span className="path-badge">BO > RX Prescription Review</span>에서 검토 목록으로 조회할 수 있습니다.
- **옵티션이 있는 스토어** : 해당 메뉴에서 직접 `Confirm` 처리가 가능합니다.
- **옵티션이 없는 스토어** : Lab에서 검토 및 처리를 진행합니다.

---

## 3. 스토어 → Lab 출고 등록 및 라벨 출력

`Confirm` 처리된 RX 주문을 Lab으로 보내기 위해 출고를 등록하고 라벨을 출력합니다.

| Step | 내용 |
|:---:|---|
| **a** | `Confirm` 상태인 주문을 체크박스로 선택한 뒤 **출고 등록**을 클릭합니다 |
| | ⭐️ 작업 가능하다고 판단된 **컨펌 상태 주문만** 출고 대상입니다 |
| **b** | 출고 등록이 완료되면, <span className="path-badge">POS > 출고 라벨 프린트</span> 메뉴로 이동합니다 |
| | 출고 상세에서 포함된 주문 목록을 확인하고, 라벨 출력 버튼이 활성화되면 출력합니다 |
| **c** | 출고 완료 후 <span className="path-badge">Inventory > Outbound Order List</span>에서 출고 목록과 상태를 확인할 수 있습니다 |
| **d** | 배송 완료 시점에 입고 리스트가 자동 생성되며, Lab에서 입고 처리를 진행합니다 |

:::tip 운영 참고
스토어에서는 컨펌된 주문을 하나의 출고로 묶어 라벨을 출력한 뒤 출고 준비를 완료합니다.
배송사(Fedex) 픽업이 필요한 건은 **별도로 유선 요청**해 진행합니다. (일시 / 장소 전달)
:::
