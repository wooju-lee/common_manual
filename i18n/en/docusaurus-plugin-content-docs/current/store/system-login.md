# 📍 System Login

> Guide for logging into the IIC BO (Offline Unified Back Office) system.
>
> Path : <span className="path-badge">IIC BO</span>

---

## 1. How to Create an Account (ID)

If you need an account, you can request one through the following methods.

| Method | Description |
|---|---|
| **Slack** | Request directly through the System Operation channel |
| **Store Manager** | If you don't have a personal Slack account, request through your Store Manager |

> **Initial Password:** `Iic_bo_2025!`

- This system **logs all activities by account**, so please make sure to **use your own account** and **change the initial password immediately**.

## 2. IIC BO Login

![IIC BO Login Screen](/img/common/system-login.png)

- **Access URL:** [https://bo.systemiic.com/en/signin](https://bo.systemiic.com/en/signin)
- Enter your ID and Password, then click **Sign In** to log in.

<div className="blockquote-warning">

> **Account Locked After 5 Failed Attempts**  
> If you enter the wrong password **5 consecutive times**, your account will be deactivated and you will not be able to log in.  
> In this case, please contact the IT team through the **System Operation channel (Slack)** or your **Store Manager** to request account reactivation.

</div>

## 3. Password Reset

![Password Reset Screen](/img/common/password-reset.png)

You can reset your password using the **Password Reset** link at the bottom of the login screen.

### Reset Procedure

> 1. Click **Password Reset**
> 2. Enter your ID → A **verification email** will be sent to the registered email address
> 3. Enter the **6-digit verification code** received
> 4. Set a new password

<div className="blockquote-warning">

> The verification code is valid for **3 minutes**. If it expires, you will need to restart the reset process to receive a new code.

</div>

### Password Requirements

| Rule | Details |
|---|---|
| **Combination** | Must include at least **2 of the following**: uppercase, lowercase, numbers, special characters |
| **Minimum Length** | 8 characters or more |
| **Allowed Special Characters** | `!` `@` `#` `$` `%` `-` `_` etc. |
| **Restrictions** | Cannot reuse previous password |
| | Cannot use the same password as your ID |
